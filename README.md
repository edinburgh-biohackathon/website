# Edinburgh BioHackathon website

Static site for Edinburgh BioHackathon — https://edinburghbiohackathon.co.uk

- `index.html` — the whole page (HTML, CSS, JS inline)
- `img/` — photos, partner logos, team headshots, brand marks

Deployed with Cloudflare Pages: every push to `main` goes live automatically. No build step.

Contact: biohackathon@ed.ac.uk
